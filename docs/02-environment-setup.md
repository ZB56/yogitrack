# Project Environment Setup (course document)

An approach to set up the development environment and create a CI/CD pipeline
for continuous incremental delivery of a web application hosted on Heroku.

## Technologies
1. MERN stack.
2. MongoDB, mongosh, and MongoDB Compass for local development.
3. MongoDB Atlas for database on cloud.
4. Heroku for application deployment on cloud.
5. Development tools: VSCode, Git.

## Local software installations
1. VSCode — https://code.visualstudio.com/download
2. Node.js — https://nodejs.org/en/download
3. MongoDB Community — https://www.mongodb.com/try/download/community
4. Git — https://github.com/git-guides/install-git
5. Heroku CLI — https://devcenter.heroku.com/articles/heroku-cli

## Platform accounts
- MongoDB Atlas — https://www.mongodb.com/atlas (free up to a certain data size)
- Heroku — https://www.heroku.com (use Eco Dyno plan as the cheapest option)
- GitHub — https://github.com/ (free)
